# طرح طراحی — Liquid Glass

> بازطراحی کامل رابط کاربری با الهام از **iOS 26 Liquid Glass**.
> جایگزین طرح قبلی («دفترچهٔ تبادل»).

## ۱. صادقانه: چه چیزی واقعی است و چه چیزی تقریب

اسکیل `liquid-glass-design` برای **کد نیتیو اپل** نوشته شده (SwiftUI / UIKit / WidgetKit).
در وب معادل مستقیمی وجود ندارد.

| قابلیت Liquid Glass | در این پروژه | وضعیت |
|---|---|---|
| بلور پس‌زمینه | `backdrop-filter: blur(26px) saturate(190%)` | **تقریب نزدیک** |
| اشباع رنگ پشت شیشه | `saturate(190%)` | **تقریب نزدیک** |
| بازتاب_specular لبه | `inset 0 1px 0` + `::before` رادیالی | **تقریب** |
| واکنش به اشاره‌گر | `--mx/--my` از `pointermove` در JS | **تقریب** |
| شکست نوری واقعی محتوا | ray-traced در موتور سیستم‌عامل | **غیرقابل پیاده‌سازی در CSS** |
| واکنش به حرکت/چرخش دستگاه | حسگر شتاب‌سنج | **غیرقابل پیاده‌سازی** |
| ظرف واحد برای گروه شیشه‌ها | کلاس‌های `.glass-*` با blur یکسان | **هم‌برند** |

## ۲. نکتهٔ صادقانه دربارهٔ نسخه

اسکیل برای **iOS 26** نوشته شده است. رنگ‌های سیستمی iOS در نسخه‌های مختلف پایدار بوده‌اند
و همان‌ها استفاده شده‌اند. جزئیات طراحی اختصاصی **iOS 27** در دسترس مستند نبود و
از خود ساخته نشده است.

## ۴. انحراف عمدی از رنگ iOS

رنگ آبی استاندارد اپل `#007AFF` است، ولی **سفید روی آن فقط ۴٫۰۲:۱ کنتراست می‌دهد** —
زیر حد ۴٫۵:۱ برای متن ۱۶ پیکسلی. پس پرکننده‌ها را تیره‌تر کردم:

| کاربرد | رنگ اپل | رنگ ما | کنتراست سفید |
|---|---|---|---|
| دکمهٔ اصلی | `#007AFF` | `#006BDF` | ۵٫۰۴:۱ |
| دکمهٔ خطر | `#FF3B30` | `#D62820` | ۵٫۰۲:۱ |

برای متن‌های رنگی روی پس‌زمینهٔ کم‌رنگ، نسخهٔ تیره‌تر هر رنگ استفاده شده تا کنتراست
از ۴٫۵ بگذرد: `#186E34` برای سبز (۵٫۶۱:۱)، `#9A5B00` برای نارنجی (۴٫۸۲:۱).

**کنتراست به‌صورت عددی بررسی شده، نه حدسی.** همهٔ جفت‌رنگ‌ها ۴٫۵:۱ یا بالاترند.

## ۵. قواعد رعایت‌شده از خود اسکیل

| قاعدهٔ اسکیل | اجرا |
|---|---|
| «شیشه را روی همه‌چیز نگذار» | شیشه فقط روی نوار بالا، کارت‌ها، کاشی‌ها، دکمه‌ها و منوی کشویی |
| «شیشهٔ تودرتو کارایی را خراب می‌کند» | سطرهای فهرست شیشه ندارند؛ روی یک پنل شیشه‌ای می‌نشینند |
| «`interactive()` فقط روی عناصر تعاملی» | بازتاب متحرک فقط روی `.glass` قابل کلیک و `.btn` |
| «پس‌زمینهٔ کدر پشت شیشه، جلوی شفافیت را می‌گیرد» | پس‌زمینه چهار گرادیان شعاعی رنگی |
| «کنتراست متن روی شیشه» | بررسی عددی، اصلاح رنگ‌ها |
| «فرایند را روی ظاهرهای مختلف تست کن» | حالت روشن و تیرهٔ جدا + fallback |

## ۶. پس‌زمینه

Liquid Glass بدون یک پس‌زمینهٔ رنگی پشتش بی‌معناست — شیشه باید چیزی را تار کند.
چهار لکهٔ رنگی شعاعی با رنگ‌های سیستمی iOS روی `body::before` با `position: fixed`:

```
بنفش ایندیگو ↘ بالا-راست
قرمز ↗ بالا-چپ
فیروزه‌ای ↙ پایین-وسط
نارنجی ↘ میانه-راست
```

## ۷. پشتیبانی مرورگر

| مرورگر | رفتار |
|---|---|
| Safari / Chrome / Edge جدید | بلور کامل + بازتاب |
| Firefox جدید | `backdrop-filter` پشتیبانی می‌شود |
| مرورگر بدون `backdrop-filter` | سطح مات خوانا + حذف گرادیان |

با `@supports not (...)` پیاده شده: شیشه به سطح سفید مات تبدیل می‌شود و سایت
**کاملاً خوانا می‌ماند**. شیشه یک افزایش تدریجی است، نه یک وابستگی.

## ۸. دسترس‌پذیری

- `prefers-reduced-motion` — تمام انیمیشن‌ها و بازتاب متحرک خاموش می‌شود
- فوکوس صفحه‌کلید با `outline` آبی ۲ پیکسلی روی همهٔ عناصر
- حداقل ناحیهٔ لمس ۴۴ پیکسل
- `aria-label` روی کلید تعویض پوسته
- تعویض پوسته در `localStorage` ذخیره می‌شود
