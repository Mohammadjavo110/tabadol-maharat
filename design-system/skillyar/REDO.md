# طرح طراحی — «دفترچهٔ تبادل»

> نقد طراحی قبلی و بازطراحی کامل فرانت بر پایهٔ اسکیل `frontend-design`.

## ۱. نقد طراحی قبلی

طراحی قبلی دقیقاً همان الگویی بود که اسکیل «تلهٔ طراحی تولیدشده با AI» نامیده است:

| ایراد | نشانه در نسخهٔ قبلی |
|---|---|
| کیت کارت SaaS | هر قطعه محتوا یک `.card` گرد با `border-radius` یکسان و `box-shadow` یکسان |
| گرادیان تزئینی | هیرو با `linear-gradient` بنفش و یک `::after` دایره‌ای |
| هاو��ر روی همه‌چیز | `translateY(-4px)` روی **تک‌تک** کارت‌ها — اسکیل صریحاً این را نشانهٔ AI می‌داند |
| کروم قالب | فلش `→` چسبیده به متن دکمه‌ها، جداکنندهٔ `—` در فیلدهای اطلاعاتی |
| بی‌ربطی با موضوع | رنگ و فرم هیچ نسبتی به «تبادل مهارت» نداشت |
| عرض خط نامناسب | کانتینر تا ۱۳۲۰px متن فارسی را در یک خط می‌کشید |

## ۲. ریشه در موضوع پروژه

این سامانه **پول مبادله نمی‌کند — مهارت مبادله می‌کند.** پس هستهٔ بصری باید «جفت شدن» باشد:
من چه دارم ⟵ ⟶ تو چه می‌خواهی.

زبان بصری از **دفترچهٔ ثبت** وام گرفته می‌شود: کاغذ، مرکب، خط‌کش افقی. خط‌های نازک
جداکنندهٔ ستون‌ها اطلاعات رمز می‌کنند (چه چیزی / چه کسی / چه سطحی) — تزئین نیستند.

### موجود‌ترین چیز در جهان این محصول

**یک جفت واقعیِ مهارت که همین حالا در دیتابیس در جریان است.** هیرو صفحهٔ اصلی یک
تبادل واقعی از دیتابیس را نشان می‌دهد، نه یک جملهٔ تبلیغاتی. این همان چیزی است که
اسکیل «باز کردن با مشخص‌ترین چیزِ دنیای موضوع» می‌خواهد.

## ۳. توکن‌ها

### رنگ

| نام | مقدار | نقش |
|---|---|---|
| `--ink` | `#11242E` | مرکب اصلی — متن و سطوح تیره |
| `--ink-2` | `#3E5A67` | متن ثانویه |
| `--ink-3` | `#6E8794` | متن کم‌رنگ و کمکی |
| `--paper` | `#F6F8F7` | زمینهٔ کاغذی سرد (نه کرم گرمِ کلیشه‌ای) |
| `--surface` | `#FFFFFF` | سطح محتوا |
| `--rule` | `#D8E1E3` | خط‌کش نازک — جداکنندهٔ ستون‌ها |
| `--saffron` | `#A86300` | **فقط** برای کنشِ قابل انجام و وضعیت «در انتظار شما» |
| `--saffron-wash` | `#FBF1DE` | پس‌زمینهٔ کم‌رنگ زعفرانی |
| `--sea` | `#0C6470` | نوع «خدمت» |
| `--sea-wash` | `#E2F0F1` | پس‌زمینهٔ کم‌رنگ فیروزه‌ای |
| `--clay` | `#96332A` | رد / خطر / حذف |
| `--clay-wash` | `#F8E8E5` | پس‌زمینهٔ کم‌رنش |
| `--moss` | `#3A6B45` | تأیید / تکمیل |

منطق رنگ: **زعفرانی فقط و فقط جایی می‌آید که کاربر کاری می‌تواند بکند.** اگر زعفرانی
همه‌جا باشد، معنا ندارد.

### تایپوگرافی

یک خانواده: **وزیرمتن**. نقش‌ها با وزن و اندازه تفکیک می‌شوند، نه با خانوادهٔ دوم —
چون فونت فارسی دومِ هم‌سطح وجود ندارد و فونت نمایشی لاتین در متن فارسی جایی ندارد.

| نقش | وزن | اندازه |
|---|---|---|
| نمایشی هیرو | 800 | `clamp(2rem, 5vw, 3.4rem)` |
| عنوان صفحه | 800 | `clamp(1.5rem, 3vw, 2.1rem)` |
| عنوان بخش | 700 | `1.25rem` |
| عنوان ستون دفترچه | 700، `letter-spacing: 0` | `1rem` |
| متن | 400 | `1rem`، `line-height: 1.9` |
| دادهٔ کوچک | 500 | `0.8rem` |

- طول خط محدود: `--measure: 66ch` روی متن‌های پیوسته
- فاصلهٔ خطوط ۱٫۹ (وزیرمتن کشیدگی عمودی زیادی دارد؛ ۱٫۵ برای فارسی کم است)
- بدون حروف بزرگ برای برچسب، بدون جداکنندهٔ نقطه‌ای، بدون `→` در متن دکمه

## ۴. اصلاحات نسبت به نسخهٔ اول طرح

| مورد | طرح اولیه | تغییر | چرا |
|---|---|---|---|
| پس‌زمینه | کاغذی با ته‌رنگ | **کاملاً سرد** `#F6F8F7` | کرم گرم trait #1 است؛ سرد یک انتخاب است |
| تأکید | بنفش | **زعفرانی، محدود** | رنگ به یک معنا گره خورد |
| کارت‌ها | کارت گرد | **سطر دفترچه با خط‌کش** | ساختار اطلاعات را رمز می‌کند |
| سایه | `box-shadow` روی همه | **حذف کامل** سایه | سایهٔ خاکستری یکسان trait #4 است |
| هاور کارت | بالا پریدن | **فقط جابه‌جایی خط زیرین** | آرام‌تر، تحریریه‌تر |
| نوار پیشرفت | دات سطح | **میلهٔ سطح** | دات‌ها نقطهٔ قوت Bootstrap است؛ میله خواناتر است |
| آمار | سه کارت | **عدد + خط زیرین**، بدون قاب | یکسانی همه‌چیز خسته‌کننده است |
| دکمه | متن + `→` | **آیکون دوسویه** | نماد در تصویر، نه در متن |
| حرکت | هاور همه‌جا | **فقط یک لحظهٔ ورود در هیرو** | اسکیل: پراکندگی حرکت = خوانش AI |

## ۵. چه چیزی از Bootstrap باقی می‌ماند

Bootstrap **رفتار** می‌دهد، نه **ظاهر**:
`navbar-collapse`، `dropdown`، `offcanvas`، کنترل‌های فرم، شبکه، `visually-hidden`،
`btn` برای حالت‌های فوکوس.

ظاهر همه‌چیز با `main.css` بازنویسی می‌شود. `border`، `border-radius` و `box-shadow`
پیش‌فرض Bootstrap روی `.card` خنثی می‌شوند.

## ۶. کف کیفیت

- واکنش‌گرا تا ۳۶۰px بدون اسکرول افقی
- فوکوس صفحه‌کلید همه‌جا دیده می‌شود
- `prefers-reduced-motion` رعایت می‌شود
- کنتراست متن ۴٫۵:۱ به بالا
- ناحیهٔ لمس حداقل ۴۴px
- Bootstrap برای باز شدن منوی موبایل لازم است
